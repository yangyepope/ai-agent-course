    "content": "Redis maxmemory-policy 用于控制内存淘汰策略"
}

# 为什么 embedding 是 dense_vector？

假设：

Redis maxmemory-policy 是什么？

Embedding：

[0.013,
 -0.092,
 0.221,
 ...
 0.045]

文档：

Redis 的 maxmemory-policy 决定 Redis 内存不足时如何淘汰数据。

也变成：

[0.018,
 -0.087,
 0.217,
 ...
 0.041]

两个向量距离比较近。

所以：

query
 ↓
embedding
 ↓
kNN
 ↓
semantic similarity

KNN = k-Nearest Neighbors（k 个最近邻），一个检索/分类的经典思路。

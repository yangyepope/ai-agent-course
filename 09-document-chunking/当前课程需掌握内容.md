# 一、今天你必须掌握的知识

到第 09 课结束，你应该能够解释：

1. Document Loader
负责：
原始文件 → Document
2. Chunking
负责：
大 Document → 小 Chunk
3. Embedding
负责：
Chunk → Vector
4. Vector Store
负责：
Vector 存储 + 相似度搜索
5. Metadata
负责：
来源
页码
文档
权限
分类
租户
等额外信息
